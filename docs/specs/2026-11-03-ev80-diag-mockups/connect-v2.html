First start for a new owner (last step)

Recognition, kept unobtrusive: it only appears when an owner has two or more vans, and it is only a suggestion banner. It never switches on its own. It compares the odometer (when the van is on) or the BMS energy counter (when only the battery is awake, e.g. charging) with what each profile last saw. With one van there's never a question.
Back up writes one compressed file with the profile, its notes and all its sessions; Restore reads it back (also on a new phone). Delete asks twice and offers a backup first.
Adapter list: the LX and USB-CAN are marked as full logging; any other Bluetooth adapter gets a warning that it may miss frames, so shared logs from it aren't mistaken for complete ones.
