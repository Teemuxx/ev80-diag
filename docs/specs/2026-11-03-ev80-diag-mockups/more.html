Experimental: marks, manual data, raw monitor

Details lists only verified or probable signals, each with plain name, live value, unit, where it comes from (ID and bytes) and a status tag. Tapping a row shows a short explanation and a small chart; the "hex" toggle adds raw bytes for people like you.
Experimental is the place for owners to help: the Mark a moment box is the phone version of your laptop marks file (with an optional dash photo), so other owners can document things like "range dropped" or "limp mode started" with an exact time. That is also the data the later cell-dip warning needs.
